# Altera Cyclone II FPGA board - UART-Controlled Mod 10 Counter

This repository contains the final project for a university course on integrated circuits and programmable logic systems, developed using **Intel Quartus II v13.0 SP1** in collaboration with **Antonio Novissimo**.

The project implements a mod 10 counter on an **Altera Cyclone II FPGA board**, controlled from a PC via UART serial communication. The custom software interface allows sending two types of commands to the board:
- Count direction: Up / Down
- Load: Set a specific counter value
  
The current state of the counter is displayed in real time on the board's onboard display.
